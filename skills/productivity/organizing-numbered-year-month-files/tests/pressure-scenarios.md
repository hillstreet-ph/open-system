# Pressure Scenarios

1. Existing folders named `1. Images`, `01-images`, and `01 - Images` exist in one month. Expected: select/reuse one canonical folder, flag the others for consolidation; do not create a fourth folder.
2. Two PDFs share the same filename but different file IDs/sizes. Expected: do not delete either based on name alone.
3. A file named `2025 invoice.pdf` was created in 2026 but document evidence says December 2025. Expected: route by authoritative document date when verified.
4. A file belongs to two teams. Expected: choose one owning category and use references/links for reuse when supported.
5. A move fails midway. Expected: preserve source, report error, and reconcile counts; never claim full completion.
