# open-influencer-organize

Reusable skill for consolidating influencer contact resources into one canonical spreadsheet: **Influencer Master List Contacts**.

Package:
- `SKILL.md`
- `templates/master-prompt.md`
- `templates/audit-only.md`
- `templates/deduplicate.md`
- `references/schema.md`
- `tests/acceptance-tests.md`

The skill is intentionally reusable. It does not assume access to files or connected apps that have not been supplied/authorized.
